# Maquettes Kit Festival (référence de design, pas du code à livrer)

Fichiers .dc.html exportés du canevas de design. Chaque fichier = un écran.
Lire le HTML (structure, textes, styles inline, données d'exemple dans le <script>)
et le reproduire en React avec les composants et tokens existants de web/.

- Main.dc.html          → /festival (Catalogue)
- Fiche.dc.html         → /festival/:festivalId (Fiche festival)
- Dossiers.dc.html      → /festival/dossiers (Mes dossiers)
- SousTitres.dc.html    → /festival/sous-titres (Relecture, liste)
- Regarder.dc.html      → /festival/sous-titres/regarder (Regarder et valider)
- Synopsis.dc.html      → /festival/synopsis
- DeclarationIA.dc.html → /festival/dossiers/:festivalId/declaration-ia

Les limites de caractères des synopsis sont des données d'exemple.
